# CP6.2 — verified XAudio2 playback

CP6.0 crashed because the desktop Dawn DLL was a mandatory startup dependency.
CP6.1 restored safe launch and proved the XAudio2 API path returned success, but
no tone was audible on the physical Xbox Series X.

CP6.2 keeps Dawn completely excluded and upgrades the audio acceptance test so
API return codes alone cannot pass.

## Playback test

The Xbox app now:

- creates the XAudio2 engine and mastering voice
- creates a 32 kHz stereo PCM source voice
- queues two seconds of audio
- plays a 660 Hz tone for one second followed by 880 Hz for one second
- uses a substantially higher test amplitude than CP6.1
- explicitly calls `StartEngine`
- starts the source voice
- waits 350 ms
- queries `IXAudio2SourceVoice::GetState`
- passes only if `SamplesPlayed > 0` while the buffer is still queued

A successful launch should therefore produce both an audible two-note tone and
a dark blue/black diagnostic screen.

Gray means the XAudio2 graph did not actually advance samples.

The executable still has no `webgpu_dawn.dll` startup dependency.
