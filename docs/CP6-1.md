# CP6.1 — safe XAudio2 recovery

CP6.0 crashed at process launch on the physical Xbox Series X.

The packaged desktop Dawn binary was inspected and found to import desktop-only
Windows components, including USER32.dll and desktop console/process APIs.
Because BlueWakeUWP.exe linked webgpu_dawn.dll normally, the Xbox loader had to
load that incompatible DLL before application code could run. That explains the
pre-diagnostic launch crash.

CP6.1 returns to the physically confirmed CP5 codebase and adds only the UWP
XAudio2 probe. Dawn is not linked, loaded, or packaged in this checkpoint.

## Acceptance criteria

- all CP1-CP5 tests remain intact
- BlueWakeUWP.exe imports XAudio2_9.dll
- BlueWakeUWP.exe does not import webgpu_dawn.dll
- Xbox launch reaches the diagnostic screen
- a short low-volume 440 Hz tone plays once on startup
- dark blue/black means CP1-CP5 plus XAudio2 passed
- gray means XAudio2 initialization/playback submission failed
- holding A still turns the screen green

## Renderer next step

The prebuilt desktop Dawn package cannot be used as the Xbox runtime.
The renderer path must use a Dawn build compiled specifically for
UWP/AppContainer, after which the existing CoreWindow surface experiment can be
reintroduced without making the app loader depend on desktop USER32 imports.
